# Alba’s Streetfood

Professionelle, mehrsprachige Website für **Alba’s Streetfood** in Leutkirch im Allgäu.

## Veröffentlichung

Die Website wird automatisch über GitHub Pages veröffentlicht, sobald die Datei `site-package.tar.gz` im Hauptverzeichnis aktualisiert wird.

Vorgesehene Adresse:

`https://julik527.github.io/-albas-streetfood/`

## Technischer Aufbau

- statisches HTML, CSS und JavaScript
- Deutsch, Englisch und Albanisch
- interaktive Satelliten- und Straßenkarte mit Leaflet
- responsive Darstellung für Smartphone, Tablet und Desktop
- Speisekartenfilter und Preisrechner
- Besuchsplaner und Kalenderdatei
- Galerie, Offline-Seite und installierbare Web-App
- automatische Qualitätsprüfungen vor jedem GitHub-Pages-Deploy

## Veröffentlichungsstatus

Die technische Website ist geprüft. Solange geschäftliche E-Mail-Adresse, vollständige Pflichtangaben, Allergene, Zahlungsarten und Bildrechte nicht abschließend bestätigt sind, bleibt die Website für Suchmaschinen gesperrt und enthält entsprechende Hinweise in den Rechtstexten.
